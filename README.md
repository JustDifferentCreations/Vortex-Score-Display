# Vortex Control Score Display

The scoreboard and game controller for **Vortex Control**, a vertical pinball machine that is still in progress. Four 7-segment readouts show the balls left, the lit hole value, the score and the credits, and the board runs the game rules.

Designed by [Just Different Creations](https://justdif.com) in Lufkin, Texas. See it on the [PCB-Only Builds](https://justdif.com/pcb-only-builds/) page.

## How the game plays

- **Coin** adds a credit (up to 99). The credit lamp output is on whenever credits are above zero.
- **Start** spends a credit and begins a game with 3 balls and a lit hole value of 100.
- **Hole** adds the lit hole value to the score. The next hole is worth 100 more (up to 999).
- The lit hole value **ticks down by 10 about every 10 seconds** while you play (not below 50), so faster shots score more.
- Hitting a hole worth **more than 700 adds a ball** and lights the Ball Added lamp for about 10 seconds.
- **Drain** takes a ball. When the last ball drains, the Game Over lamp comes on.
- **Tilt** ends the game at once and lights the Tilt and Game Over lamps.
- **Attract mode:** between games, while the attract input is held low, the ball, hole and score readouts run a chasing-segment animation.

Every switch input has a software lockout so bouncing contacts and a swinging tilt pendulum only count once.

## Displays

Four TM1637 7-segment driver modules, each on its own bit-banged clock/data pair (`tm1637_custom.h`):

| Readout | Digits | CLK | DIO |
| --- | --- | --- | --- |
| Ball(s) | 2 | PD0 | PD1 |
| Lit hole value | 3 | PD2 | PD3 |
| Score | 6 | PD4 | PD5 |
| Credit(s) | 2 | PD6 | PD7 |

## Inputs and outputs (AVR64DU28)

| Pin | Name | Function |
| --- | --- | --- |
| PA0 | MC1 | Coin / credit switch (interrupt) |
| PA1 | MC2 | Start button (interrupt) |
| PA2 | MC3 | Hole switch (interrupt) |
| PA3 | MC4 | Drain switch (interrupt) |
| PA4 | MC5 | Tilt pendulum (interrupt) |
| PA5 | MC6 | Attract mode enable (active low) |
| PA7 | MC8 | Credit lamp output (high when credits > 0) |
| PF0 | B_ADD_LT | Ball Added lamp (active low) |
| PF1 | GM_OVR_LT | Game Over lamp (active low) |
| PC3 | TILT_LT | Tilt lamp (active low) |

## Building and flashing

- MPLAB X IDE with the XC8 compiler (built with v3.10)
- Programmer: PICkit 5
- Pins, clock and pin-change interrupts are set up with MPLAB Code Configurator (MCC Melody). The `mcc_generated_files` folder is not in this repo. Open the project in MPLAB X, open MCC (it loads `AVR64DU28_Score_Display.mc3`), click **Generate**, then build and program the board.

Vortex Control is still being built, so this code will keep changing.
